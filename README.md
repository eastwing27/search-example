## Search Example App

To run the app locally:
 * npm install
 * npm run dev

This app is Next.js based but aimed to demonstrate my front-end React skill. The back-end part is created to mock the search results.
The app uses custom CSS styles (not Tailwind CSS) as it is required to minimize the number of extra libraries.
For the same reason, I used Next Router instead of react libs line react-router-dom.
